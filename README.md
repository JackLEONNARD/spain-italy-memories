# 西意之旅 · 公开旅行手记

无需登录的静态旅行网站，支持每日行程、城市筛选、交互路线与餐饮标记。没有票据 PDF、私人图片、订单号码、联系人及费用记录。

网页核心功能不依赖外部 CDN。街道底图需要点击按钮后联网加载，Google Maps 外链需要可访问对应服务的网络。

## 发布到 GitHub Pages

将本目录文件上传到一个新的公开仓库根目录，保留 index.html 文件名。

进入仓库 Settings → Pages → Deploy from a branch → main → /(root) → Save。

不要上传原来的私有项目、tickets 或 records 文件夹。

GitHub Pages 的大陆访问需按具体网络实测，本项目不承诺大陆访问稳定性。
